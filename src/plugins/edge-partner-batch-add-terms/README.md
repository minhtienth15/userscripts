# Edge Partner Center - Batch Add Search Terms

A userscript that adds a "Batch Add" button next to "Add Term" on the Microsoft Edge Partner Center extension listing page, allowing you to add multiple search terms at once using comma-separated input.

## Features

- **Batch Input**: Enter multiple search terms separated by commas in a textarea dialog
- **Live Validation**: Real-time feedback on term count (max 7), character limit (30 chars/term), and total word count (max 21)
- **Auto Close**: Dialog closes automatically after all terms are added

## Installation

1. Install a userscript manager like [Tampermonkey](https://www.tampermonkey.net/) or [Greasemonkey](https://www.greasespot.net/)
2. Download the userscript from <https://github.com/rxliuli/userscripts/releases/latest/download/edge-partner-batch-add-terms.user.js>

## How to Use

1. **Open Listing**: Navigate to your extension's Store Listings page on the Edge Partner Center
2. **Click Batch Add**: Find the "Batch Add" button next to "Add Term" in the Search Terms section
3. **Enter Terms**: Type your search terms separated by commas (e.g. `substack export, substack backup, newsletter backup`)
4. **Add All**: Click "Add All" and the terms will be added one by one automatically
